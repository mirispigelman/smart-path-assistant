# Smart-path - AI-Powered Supermarket Shopping Assistant

SmartPath is an innovative web application designed to optimize and streamline the grocery shopping experience. By leveraging the power of generative AI, the application calculates the most efficient shopping path within a supermarket based on the user's shopping list, saving time and reducing hassle.

##  Features

- **AI-Driven Path Optimization:** Automatically categorizes and sequences shopping list items to create the ultimate logical walking path through the store using the Gemini API.
- **Smart Shopping List:** Easy-to-use interface for adding, updating, and managing grocery items in real-time.
- **Full-Stack Architecture:** Seamless communication between a responsive frontend and a robust backend API.

##  Tech Stack

**Frontend:**
- React.js
- HTML5 & CSS3 / Tailwind CSS
- Axios (API Integration)

**Backend:**
- Node.js
- Express.js
- Google Gemini API (AI Orchestration)

##  Prerequisites

Before running this project locally, ensure you have the following installed:
- Node.js (v14 or higher)
- npm (Node Package Manager)
- A Google Gemini API Key
